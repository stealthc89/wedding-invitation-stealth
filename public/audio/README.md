# Background Music

## Required File

Place your music file here:
- **Filename**: `its-you-max.mp3`
- **Song**: "It's You" by Max
- **Format**: MP3 (320kbps recommended for high quality)

## High-Resolution Audio Recommendations

For best quality, use one of these formats:
1. **MP3 320kbps** (recommended) - Best balance of quality and file size
2. **AAC 256kbps** - Excellent quality, Apple's format
3. **MP3 256kbps** - Good quality, smaller file

## How to Add the Music

1. Download "It's You" by Max in high-quality format:
   - iTunes/Apple Music: AAC 256kbps
   - Amazon Music: MP3 320kbps
   - Spotify: Premium download at 320kbps (convert if needed)

2. Convert to MP3 if needed (using iTunes, VLC, or online converter)

3. Rename the file to `its-you-max.mp3`

4. Place it in this directory (`public/audio/`)

## Legal Note

Ensure you have the proper rights/license to use this music on your website.

## Music Controls

The website includes floating music controls in the bottom-right corner:
- Play/Pause button
- Mute/Unmute button
- Auto-plays on page load (browser permitting)
- Volume set to 50%
- Loops continuously
